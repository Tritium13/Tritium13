## Hi, I'm Björn 👋

Biochemist and molecular biologist (MSc, University of Potsdam) working where biology meets image analysis.
I like turning images into numbers – and building pipelines that anyone can rerun.

🔎 Currently looking for a PhD position in bioimage analysis / cell biology.

**Microscopy & bioimage analysis**
- Live-cell confocal imaging (Airyscan, Zeiss LSM 880, Leica TCS SP8) in *Arabidopsis*, *Capsella*, *Drosophila* and zebrafish
- Fiji/ImageJ macro pipelines, kymograph analysis, mixed models (LMM/GMM) for the statistics
- Code from my thesis work will be published here together with the paper

**After hours: from microscopes to telescopes**

[**astro-pipeline**](https://github.com/Tritium13/astro-pipeline) – a transparent, reproducible Python pipeline that turns public
JWST data from the MAST archive into colour images. Every step and every decision is documented,
scientific and aesthetic choices are labelled as such.
